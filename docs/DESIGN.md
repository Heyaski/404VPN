# 404VPN — дизайн-система

Источник: https://404studiotech.ru/ (бренд 404 Studiotech). iOS-приложение и админка должны выглядеть как продукты этой студии.

## Характер

Тёмная «инженерная» эстетика: почти чёрный фон с холодным синим подтоном, мятно-зелёный акцент со свечением (glow), тонкая фоновая сетка, терминальные мотивы (моноширинные подписи, `</>`, `{ }`, окно терминала), пилюльные кнопки. Заголовки — жирный Inter (weight 800), технические подписи — IBM Plex Mono в верхнем регистре с разрядкой.

## Типографика

- Основной: **Inter** (fallback: system-ui). Заголовки — weight 800, плотный трекинг.
- Технический: **IBM Plex Mono** — коды доступа, IP, суммы в таблицах, метки-капсы с letter-spacing (`ИНЖЕНЕРНАЯ СТУДИЯ`-стиль).
- В iOS: SF Pro как системный fallback допустим, но заголовки и моно-элементы держат тот же характер (SF Mono для кодов, heavy для заголовков).

## Формы и эффекты

- Скругление: 8px базовое (кнопки, инпуты, карточки); большие CTA — полные «пилюли».
- Главная кнопка: заливка `accent`, текст `accent-contrast`, мягкое свечение `accent-glow` (box-shadow), hover — `accent-strong`.
- Вторичная кнопка: прозрачная, бордер `border-strong`, текст `fg`.
- Карточки: `surface` + бордер `border`, тени глубокие мягкие (dark: `0 8px 28px rgba(0,0,0,.5)`).
- Фон экранов: `bg` + едва заметная сетка `grid-line` (шаг ~32px).
- Тёмная тема — основная; светлая — вторичная (в админке — переключатель, iOS — можно только dark в MVP).

## Приложение к продуктам

**iOS-приложение:** тёмный экран, крупная кнопка-«кольцо» подключения VPN с зелёным свечением в состоянии connected; статус — моно-капсом (`CONNECTED` / `OFFLINE` / `SUSPENDED`); баланс и остаток дней — крупный Inter 800 + моно-подпись; ввод кода — моноширинное поле с автогруппировкой XXXX-XXXX-XXXX-XXXX.

**Админка (React):** тёмный дашборд на тех же токенах (CSS-переменные выше — скопировать как есть), таблицы с моно-цифрами, зелёные бейджи статусов, сетка на фоне логин-экрана. Логотип: «404» зелёным + «VPN» белым, в стиле «404Studiotech».

**Telegram-бот:** текстовая айдентика — лаконичный технический тон, код в моноширинном блоке, без обилия эмодзи (максимум ✅/⚠️ в статусах).
